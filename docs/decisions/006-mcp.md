# ADR-006: Official MCP Go SDK behind Kernel tool policy

## Context

MCP is a first-class capability, but the wire protocol and SDK lifecycle must not become the agent's semantic model or bypass permissions and event emission.

## Decision

Use `github.com/modelcontextprotocol/go-sdk` for protocol client transport and tool discovery/calls. Wrap each discovered tool in a Kernel registration with explicit project/run policy, argument validation, idempotency behavior, timeout and artifact rules. Pin an SDK version and negotiate supported protocol revisions deliberately.

## Alternatives

Roll a custom MCP transport; execute arbitrary tools discovered over MCP without a policy registry.

## Consequences

Uses the official Go SDK while keeping audit/security contracts independent. The current latest protocol has significant lifecycle/transport updates, so upgrade compatibility is a release task.
