## 4. Ограничения и оговорки (не влияют на вердикт)

- **ESLint в проекте не настроен** — статическим анализом фронтенда служит `tsc` (`qa-logs-verify2/tsc.log` чисто). Принято как конфигурация проекта, не дефект итерации.
- **E-1 (важно для CI):** vitest без `NODE_OPTIONS` требует Node ≥22.12; на системном Node 22.11.3 — 3 unhandled на старте воркеров (полные прогоны B/C на Node 22.23.4 — 43 файла / 434 теста).
- **E-2:** нестабильный unhandled undici/jsdom в воркере vitest — окружение, на тесты не влияет.
- **E-3:** go-тулчейн из `/cache/go-toolchain`; `GOTMPDIR` вынесен на `/cache`.
- **E-4:** NFR-7 (≤1.5 с до содержательного рендера) тестом не закреплён — по условию задачи допустимо.
- **E-5:** `go test -race` невыполним в песочнице (нет gcc/cgo); компенсация — `-v -run TestConsole` (29 PASS / 0 FAIL) и `-count=2 -cpu=1,4` (ok). Сеть песочницы изолирована от стенда — живых end-to-end проверок не было.
- Data-race-устойчивость консоли подтверждена код-ревью порядка блокировок + компенсирующими прогонами, но не детектором `-race` (см. E-5).
