# Промпт T2 — Developer (frontend)

Задача: реализовать UI полного редактирования Dockerfile в форме профиля
песочницы (`debugger/src/Sandbox.tsx`).

Входы (прочитай обязательно):
- `docs/tasks/2026-10-21-sandbox-dockerfile-editing/spec.md` — §3 (D2, D6),
  §4 (контракт API), §5 (AC-8, AC-9).
- Ключевые файлы: `debugger/src/Sandbox.tsx` (форма профиля, живой preview
  через `POST /v1/workspace/sandbox-profiles/preview`), `debugger/src/workspaceApi.ts`,
  `debugger/src/locales/ru.ts`, `debugger/src/locales/en.ts`, тесты — vitest
  (см. существующие `*.test.tsx` рядом).

Что сделать:
1. Режимный переключатель формы: «Собирать из базы» / «Свой Dockerfile» (D6).
   В режиме «Свой»: textarea с текстом, предзаполненным композированным
   Dockerfile (текущий preview-поток base+packages); поля base/packages скрыты;
   при сохранении отправляется `dockerfile_override`, base/packages пусты
   (инвариант XOR из D2.1 — сервер отвергает смешение с 422, UI не должен его
   порождать).
2. Редактируемый текст проходит живую проверку через preview-endpoint
   (`dockerfile_override` в запросе): ошибки валидации (запретные инструкции
   с номером строки) показываются оператору, сохранение блокируется при
   невалидном тексте.
3. Переключение режимов и редактирование сбрасывают/перерисовывают preview;
   существующее поведение (список профилей, теги пакетов, build/pull, история)
   не регрессируется.
4. Локали ru/en: все новые строки (заголовки, подсказки, ошибки).
5. Vitest-тесты на новую логику (AC-8) + зелёный `npm run build` (AC-9).

Критерии готовности: vitest зелёный, `npm run build` зелёный, AC-8 закрыта
тестами. Ограничения: в рабочем дереве есть незакоммиченные правки
`debugger/src/{Artifacts,Dashboard,ExperienceTimeline}.tsx` и `debugger/src/locales/*`
от смежной работы — не откатывать их, локали дополнять аккуратно (добавлять
ключи, не переписывая чужие); backend-контракт бери из spec.md §4 как данность
(backend реализует параллельно другая задача). В отчёте перечисли: что сделано,
какими тестами подтверждено, что осталось.
