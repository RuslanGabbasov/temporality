# Введение

**Temporality** — открытая система наблюдаемости и накопления опыта для ИИ-агентов.

Обычный чат-бот забывает всё между сессиями, а его «память» — свалка вставленных в контекст заметок. Temporality устроен иначе: агент выполняет задачи в durable-рантайме, а система в это время фиксирует **что он знал и делал**, откуда взялись знания, как они применялись, что подтвердилось, а что оказалось ложным — и как опыт менялся со временем. При следующей задаче проверенный опыт возвращается агенту в компактном виде, не перегружая контекст.

```text
Agent Kernel ──events──▶ Journal ──projection──▶ Knowledge / Hints
     ▲                      │                         │
     └──────── hints ◀──────┴──── Experience Timeline ┘
```

## Ключевые идеи

- **Запуск (run)** — единица работы агента: durable workflow на Temporal, который переживает перезапуски, деплои и сон ноутбука. Каждый шаг журналируется.
- **Знания с происхождением.** Утверждения, извлечённые из траекторий, имеют автора, источник, статус жизненного цикла (предложено → подтверждено → оспорено…) и битемпоральную историю. Знание можно оспорить, исправить, инвалидировать — и увидеть, кем и когда.
- **Подсказки (hints)** — компактные выдержки релевантного опыта, которые система подставляет агенту перед задачей. Агент может раскопать полные первоисточники через инструменты исследования.
- **Саги** — явно отслеживаемая длительная работа, которая живёт дольше одного рана: продолжения чата, делегированные агенты и поправки присоединяются к саге автоматически.
- **Артефакты** — реестр справочных документов (регламенты, инструкции, чек-листы), которые агенты подгружают по требованию, а не держат в промпте.
- **Навыки (living skills)** — переиспользуемые процедуры с контрактом (что умеет, когда применимо, что проверять), версиями, оценками качества и управляемой человеком эволюцией.
- **Контур качества** — изменения агента применяются только поверх свежего зелёного оценочного прогона: golden-кейсы, подтверждения человеком, LLM-судья с калибровкой.
- **Безопасность по умолчанию** — песочница команд в Docker без сети и прав, подтверждения consequential-действий человеком, секреты, которые агент never видит, RBAC и оргструктура.

## Из чего состоит система

| Компонент | Что делает |
|---|---|
| **Agent Kernel** | Durable-рантайм агента: модельный шлюз, инструменты, песочница, делегирование, подтверждения, планирование |
| **Journal** | Append-only журнал событий; проекция знаний, подбор подсказок, битемпоральные запросы |
| **Workspace (чат)** | Диалог с агентом: стриминг, вложения, подтверждения, поправки к выполняющимся задачам |
| **Debugger UI** | Дашборд, трассы запусков, карта знаний, таймлайн опыта, навыки, артефакты, триггеры, администрирование |
| **Control Plane** | Пользователи, RBAC, оргструктура, токены |

Всё это поднимается одной командой `docker compose up` — PostgreSQL, Temporal, Journal, Kernel, UI и опциональные SearXNG + headless-браузер для веб-исследований.

## Для кого это

- **Команды, эксплуатирующие агентов** — видеть, что агент делал и почему, отвечать на вопросы «кто и что изменил», находить и чинить повторяющиеся ошибки.
- **Команды, развивающие агентов** — превращать опыт в проверенные знания и навыки, менять определения агентов безопасно, через контур качества.
- **Организации** — ограничивать агентов политиками, держать данные у себя, разделять доступы через оргструктуру.
