03 / GET STARTED

Поднять локально.
Подключить модель.
Запустить агента.

Минимальный путь для первого запуска. Секреты модели хранятся в локальном .env — не в репозитории.

1

Склонируйте репозиторий

Нужны Git и Docker Compose.

git clone https://github.com/RuslanGabbasov/temporality.git
cd temporality
2

Настройте модель

Скопируйте пример окружения и укажите OpenAI-совместимый API. Подойдут облачный провайдер или локальный Ollama.

cp .env.example .env
# Set TEMPORALITY_MODEL_BASE_URL
# TEMPORALITY_MODEL_ID and API_KEY
3

Запустите сервисы

Compose поднимет PostgreSQL, журнал событий, интерфейс отладки, Temporal и Agent Kernel.

docker compose up --build -d
4

Откройте интерфейс

Debugger доступен на порту 3000. Temporal UI — на 8233. Для локальной разработки авторизация выключена, если токены не заданы.

Debuggerhttp://localhost:3000
Temporal UIhttp://localhost:8233
⌘
FIRST SESSION

С чего начать после запуска

  1. Настройте провайдера модели.
  2. Создайте или выберите агента.
  3. Запустите простую задачу с проверяемым результатом.
  4. Посмотрите события запуска и предложенные знания.
  5. Проверьте происхождение и повторное использование опыта.

04 / ARCHITECTURE

События — источник правды.
