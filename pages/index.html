Цифры — из стенда,

04 / GET STARTED

Поднять локально.
Подключить модель.
Запустить агента.

Минимальный путь для первого запуска. Секреты модели хранятся в локальном .env — не в репозитории.

1

Заберите compose-файл

Нужен только Docker Compose — образы уже собраны и опубликованы для amd64 и arm64.

curl -o docker-compose.yml https://raw.githubusercontent.com/RuslanGabbasov/temporality/main/docker-compose.yml
curl -o .env.example https://raw.githubusercontent.com/RuslanGabbasov/temporality/main/.env.example
cp .env.example .env
2

Настройте модель

Укажите OpenAI-совместимый API — облачный провайдер или локальный Ollama. Ключ сохранится в локальных секретах.

# .env
TEMPORALITY_MODEL_BASE_URL=…
TEMPORALITY_MODEL_ID=…
3

Запустите стек

Compose поднимет PostgreSQL, журнал событий, интерфейс, Temporal, Agent Kernel и веб-инструменты. Мастер онбординга проведёт первый запуск: проект → провайдер → агент → песочница.

TEMPORALITY_VERSION=2026.2.11 docker compose up -d
4

Откройте интерфейс

Debugger доступен на порту 3000. Temporal UI — на 8233. Для локальной разработки авторизация выключена, если токены не заданы.

Debuggerhttp://localhost:3000
Temporal UIhttp://localhost:8233

  1. Настройте провайдера модели.

06 / HOW IT COMPARES

Не вместо вашего фреймворка.
Вокруг него.

Память (Mem0, Zep) помнит. Трассировка (LangSmith, LangFuse) показывает. Фреймворки (LangGraph, CrewAI) оркестрируют. Temporality закрывает недостающий слой: durable-исполнение и опыт с происхождением и жизненным циклом — связанный с людьми, доступами и качеством.

TemporalityПамять · Mem0, ZepТрассировка · LangSmith, LangFuseФреймворки · LangGraph, CrewAI
Durable-запуски: переживают сбои, деплои и паузы✓——± чекпоинты — через их платформу
Человек в потоке: подтверждения и вопросы в мессенджерах✓——± interrupt() — без каналов доставки
Знания с происхождением, статусом и историей✓± без верификации——
Возврат релевантного опыта в новые задачи✓✓——
Контур качества изменений: оценки, судья, гейт✓—± оценки промптов — без гейта применения—
Навыки с контрактами, версиями и эволюцией✓——± описания задач — без контракта и версий
Оргструктура, RBAC, политики, секреты✓—± роли в воркспейсе — без оргполитик—
Семантический слой знаний: локальные эмбеддинги без облака✓± облако или отдельный сервис——
Модель-супервайзер: триаж сбоев, аномалии, конфликты знаний, кандидаты в навыки✓—± трейс-анализ руками—
Метрики человеческого фактора: внимание и простой (HAB/HWT)✓—± латентность—
Self-hosted одним compose, данные у вас✓± OSS-редакции с оговорками± LangFuse OSS; LangSmith — SaaS✓

✓ — из коробки · ± — частично или через обходные пути · — — нет. Сравнение отражает типичную специализацию категорий; детали зависят от конкретного продукта. Данные собраны из открытой документации на октябрь 2026.

⟳

Durable с первого дня

Раны живут в Temporal: перезапуск сервиса, деплой или уснувший ноутбук не убивают задачу — она продолжается с места остановки.

◉

Опыт, а не свалка

У каждого знания — автор, источник и статус. Устаревшее не подсматривается, противоречия не теряются, а решаются.

⚖

Качество как процесс

Изменения агентов и навыков проходят оценки на golden-кейсах и LLM-судью с калибровкой. Человек утверждает — система не мутирует сама.

⛨

Безопасность по умолчанию

Команды — в изолированной песочнице без привилегий; секреты агент не видит; consequential-действия — только через подтверждение; RBAC и политики оргструктуры.

☕

Люди в контуре, а не в узком месте

Подтверждения и вопросы приходят в ваш мессенджер и решаются оттуда. Метрики HAB/HWT показывают, где поток упирается в людей — внимание это или простой.

⌂

Своя инфраструктура

Весь стек — одним docker compose: PostgreSQL, Temporal, журнал и UI у вас. MCP-серверы и OpenAI-совместимые модели подключаются напрямую.
