Чек-лист скриншотов для сайта и гайда

Куда класть: pages/assets/ (плоско, без подпапок). Формат — webp (cwebp -q 82 in.png -o out.webp), ширина 1280–1600px (retina ×2, если можно), тема — та, что выглядит лучше (светлая сейчас дефолт). Данные на скринах — не боевые: тестовый проект, вымышленные имена.

Гайд (RU и EN) ссылается на имена из колонки «Файл» — npm run build:docs пересобирает pages/docs/ из docs/user/.

#Как снимать аккуратно

  1. Тестовые данные: проект «demo», вымышленный клиент, файл report.md.
  2. Перед скрином закрыть тултипы/уведомления (или наоборот — если они и есть объект, как у override-панели).
  3. Браузер без лишних вкладок в кадре; масштаб 100%.
  4. Для мобильной ширины — DevTools → device toolbar → iPhone 14.
  5. Не кадрировать слишком плотно: оставь контекст (заголовок страницы).
