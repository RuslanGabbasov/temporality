## 2. Пятиосевая оценка

### Архитектура — [FAILED]
Трёхслойная модель (A) и декларативный каталог (B) не реализованы: источник истины `eventCatalog.ts` существует, но `eventSummary.ts:195–621` по-прежнему императивный switch (K-4 открыт); слои 1/2/3 не разделены, K-1 (`AgentRuns.tsx:1021`) открыт. Отчёт T2 с таблицей покрытия типов отсутствует.

### Безопасность — [FAILED]
Инвариант P-2 на уровне базового кода соблюдается (только имя/статус/причина, `eventSummary.ts:527–530`), однако обязательный автотест redaction отсутствует, а требование «сырой JSON недоступен из таймлайна» нарушается текущим отображением сырых аргументов/полей (`AgentRuns.tsx:1021`, `:302`) вплотную к таймлайну без выделенного слоя 3. Подтверждения от T2/T3 нет.

### Надежность — [FAILED]
K-3 не закрыт: `.catch(() => ({ events: [], count: 0 }))` в `AgentRuns.tsx:524–526` по-прежнему глотает ошибки статусов без `partial: true`, индикатора «статусы недоступны» и логирования. Нет приложенного вывода регрессионных прогонов (DoD 4), нет новых тестов. AbortController/`document.hidden`-пауза не реализованы (`AgentRuns.tsx` — без упоминаний `document.hidden`).

### Производительность — [FAILED]
NFR-1 не выполнен: 4 скана журнала на открытие (`AgentRuns.tsx:519, 523–526`) + N+1 (`AgentRuns.tsx:545–551`); NFR-2 не выполнен (1 запрос страницы таймлайна на выбор не реализован); batch-эндпоинта нет. Perf-guard тестами бюджеты не закреплены (DoD 3).

### Управляемость — [FAILED]
Отчёты T1–T4 полностью отсутствуют (нет каталога `reports/`), т.е. ни один DoD-этап не имеет подтверждения по форме (а–г) из `03-developer-prompts.md:9`. Дифф рабочего дерева состоит из изменений других саг и не может служить отчётом о проделанной работе по saga--86d5a2. Факт «ESLint не настроен» подтверждается `debugger/package.json`, но нигде не зафиксирован разработчиком, как требует DoD 5.

## 3. Критические замечания (по осям FAILED)

1. **[Управляемость] Отсутствуют отчёты T1–T4.** `debugger/docs/trace-rework/reports/` — каталог отсутствует; `find / -name 't?-report.md'` → пусто. Нарушен контракт `02-decomposition.md` («Отчёт каждого этапа сохраняется в `debugger/docs/trace-rework/reports/tN-report.md`») и форма (а–г) `03-developer-prompts.md:9`. *Исправление:* выполнить T1–T4 и приложить отчёты с диффом `Файл:Строка`, полным выводом тестов и стат. анализа, таблицей статусов.
2. **[Производительность] Бюджеты запросов не реализованы.** `debugger/src/AgentRuns.tsx:519` (отдельный запрос `run.started`) + `:523–526` (ещё 3 запроса) + `:545–551` (N+1: `fetch` деталей по каждому корневому рану в цикле) вместо batch-эндпоинта — нарушает NFR-1/NFR-2 (≤3 запроса на открытие, 1 на выбор рана). *Исправление:* серверный `GET /v1/agent/runs` (курсор, страница 50–100, статус в строке) + одна страница таймлайна на выбор; закрепить perf-guard тестами со счётчиком запросов (мок `fetch`/`observationApi`, assert ≤3 и =1).
3. **[Надежность] Тихий `.catch` (K-3).** `debugger/src/AgentRuns.tsx:524–526` — `.catch(() => ({ events: [], count: 0 }))` скрывает недоступность статусов. *Исправление:* `partial: true` + индикатор «статусы недоступны» + логирование ошибки.
4. **[Архитектура] K-4 не закрыт.** `debugger/src/eventSummary.ts:195–621` — императивный switch вместо таблицы `type → {timeline, details, raw}` на базе `eventCatalog.ts`; нет покрытия 100% типов/псевдо-инструментов/streaming-типов и generic-шаблона по §3B. *Исправление:* декларативный каталог представления + unit-тест покрытия.
5. **[Архитектура/Безопасность] K-1 не закрыт, слой 3 отсутствует.** `debugger/src/AgentRuns.tsx:1021` — `json(operation?.arguments ?? details)` показывает сырой JSON в слое 2; там же `:302` `JSON.stringify(v)`. *Исправление:* human-форма аргументов в слое 2, сырой JSON — свёрнутой секцией слоя 3 в конце детализации (и недоступным из строки таймлайна).
6. **[Безопасность] Нет автотеста secret-redaction.** Ни один тест не проверяет неотображение значений `secret.*` на всех слоях (требование DoD-2/§3C). *Исправление:* unit-тест на все три слоя (+ слой консоли), включая `secret.value_set` → «значение задано».
7. **[Архитектура/Управлемость] T3 (console://) отсутствует целиком.** `grep -rn "console://"` → 0 совпадений: нет ни серверного кольцевого буфера/эндпоинта тейла, ни клиентской ленивой подписки, вкладок stdout/stderr, маркера усечения, копирования; нет unit-тестов стриминга. *Исправление:* по `02-decomposition.md` T3 (сервер: in-memory 256 КБ/2000 строк + тейл SSE/опрос; клиент: ленивая подписка при раскрытии, стоп по `tool.completed/failed`, AbortController, пауза при `document.hidden`).
8. **[Архитектура] F/A (фильтры, поиск, URL, доступность) отсутствуют.** Нет панели фильтров/чипов/дебаунс-поиска, состояния фильтров в URL (только старые `run`/`view`, `AgentRuns.tsx:326, 332, 648`); тоггл раскрытия без aria (`AgentRuns.tsx:278–284`). *Исправление:* по §3F + ARIA-метки и клавиатурное раскрытие (Enter/Space/aria-expanded).
9. **[Управляемость] Не подтверждён статический анализ и регрессия.** Нет вывода `npm run build` и прогонов `eventSummary.test.ts`, `eventCatalog.test.ts`, `teamRuns.test.ts`, `locales.test.ts`. *Исправление:* приложить полный вывод команд в отчётах (это обязательная часть формы а–г).

*Замечание (не дефект этой саги):* присутствующий в рабочем дереве дифф относится к другим сагам (sticky-хедер «Артефактов» `Artifacts.tsx:289–326`, «Load more» `/experience` `ExperienceTimeline.tsx`/`timelineLoad.ts`, тесты вкладки «Пользователи» `Dashboard.users.test.tsx`) — его наличие не закрывает ни один пункт DoD saga--86d5a2 и не должно фигурировать в отчётах T1–T4 как их результат.
